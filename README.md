# Protocolos de Servicio · App Gastronómica

App web educativa para personal de restaurante, bar y hotelería. Funciona como PWA (instalable y offline).

## Secciones

- **📋 Protocolos** — estilos de servicio (francés, inglés, americano, ruso, buffet, room service), montaje de mesa y manejo de quejas (BLAST), con checklists.
- **🍷 Bebestibles** — protocolo de vinos y 25 cócteles (internacionales y chilenos).
- **🍷🍽️ Maridajes** — guía de qué vino acompaña cada plato.
- **🥩 Carnes** — cortes chilenos con equivalencia USA, otras carnes y puntos de cocción.
- **🌊 Productos del Mar** — pescados, mariscos y crustáceos chilenos.
- **🌽 Vegetales Chilenos** — papas chilotas, tubérculos, frutos nativos, hierbas y otros cultivos.
- **📖 Diccionario** — términos de barra, comedor y cocina.

## Funciones

- 🔎 Buscador global en todas las secciones
- ⭐ Favoritos guardados localmente
- 🌙 Modo oscuro
- ↺ Checklists con progreso guardado
- 📲 Instalable en el celular y uso sin conexión (PWA)

## Tecnología

HTML, CSS y JavaScript puro (sin dependencias). Un solo `index.html` + service worker.
